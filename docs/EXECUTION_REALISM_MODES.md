# Execution realism modes

Execution realism describes how a scenario runs. It does not describe product
depth.

| Mode | Meaning | Public status |
|---|---|---|
| Deterministic execution mode | Pure local generation from declared inputs and a fixed seed | Implemented and tested |
| Local OSS realism mode | Local third-party applications used as non-authoritative execution surfaces | Unimplemented |
| Connected calibration mode | Selected external providers used to compare behavior and fidelity | Unimplemented and not universally validated |

No mode in this repository is live accepted. The deterministic mode uses no
external credentials.
