# Privacy and synthetic data

This repository contains only fictional fixtures generated from fixed seeds.
It includes no real names, email addresses, postal addresses, account
identifiers, device identifiers, network addresses, or customer records.

PII-lineage records describe field categories and movement among fictional
systems. They exist to test discovery, provenance, normalization, and replay.
They are not real personal data and do not establish that a real organization
meets any legal, regulatory, audit, or compliance requirement.

Contributors must not add real personal data, production exports, screenshots,
logs, copied tickets, or provider state. The local checks reject common secret,
identifier, address, path, and credential patterns, but human review remains
required.
