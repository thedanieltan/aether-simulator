# Scenario library and onboarding

The scenario library exposes every scenario supported by the browser runtime:
five Enterprise Depth, five Ecosystem Depth, and six Economy Depth entries.

## Contract

Each `aether-scenario-library.v1` entry contains:

- the exact product depth and committed scenario identifier;
- a concise label and research description;
- local search tags;
- synthetic, non-authoritative, and research-preview status;
- an optional recommended marker.

The browser runtime catalog is derived from these entries. Duplicate identifiers
or unsupported depths fail validation.

## Discovery

Users can filter by product depth and search labels, summaries, or tags. Search
runs entirely in the browser. An empty result is shown as unavailable rather
than replaced with an invented scenario.

## Five-minute guided run

The guided path configures the tested enterprise retail intervention baseline
with a fixed fictional seed, scale 1, duration 80, and intervention 12. It then
opens the ordinary run workspace. The user still initiates execution and can
inspect semantic zoom, analysis, lineage, and exports through the same controls
as any other scenario.

No account, credential, Docker service, provider, real personal data, or
separate onboarding runtime is used.
